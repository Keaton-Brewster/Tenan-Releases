# Getting help with Tenan

## On the Free plan

**Report bugs as GitHub issues** on this repository:
- In the app: **Settings → Plan & Support → Report a bug** opens a report with your Tenan version and operating system already filled in.
- Or [open a bug report here](https://github.com/Keaton-Brewster/Tenan-Releases/issues/new?template=bug_report.yml).

Free support is **best effort**: reports are read and fixed as time allows, with no response time and no guarantee of a fix. Feature requests are welcome as issues too.

## On the Firm plan

Firm includes white-glove support: onboarding, a direct line, and priority fixes. Contact [keaton.brewster@millwright.solutions](mailto:keaton.brewster@millwright.solutions?subject=Tenan%20support).

## Never post client data

This repository is **public**. Leave out tenant names, environment URLs, record contents, tokens, and screenshots that show any of them. If a problem can't be described without client data, say so in the issue, and we'll find a private way to continue.

## Security issues

Please don't report security vulnerabilities in a public issue. Email [keaton.brewster@millwright.solutions](mailto:keaton.brewster@millwright.solutions?subject=Tenan%20security) instead.
